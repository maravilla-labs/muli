# Support

## Getting Help

- Use GitHub Issues for bugs and feature requests.
- For security reports, follow [SECURITY.md](SECURITY.md) and email security@maravillalabs.com.

## What to Include in Bug Reports

- OS and runtime versions
- exact reproduction steps
- expected vs actual behavior
- relevant logs and errors

## Scope of Support

This project is maintained on a best-effort basis. Response times may vary.
